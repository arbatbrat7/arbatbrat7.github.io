Что делает приложение Nafilme Studio

Nafilme Studio — внутренняя программа студии, которая работает на компьютере студии. Через вход Google она получает доступ только к YouTube-каналам самой студии, чтобы загружать на них готовые серии (YouTube Data API: загрузка видео и чтение статистики своих каналов). Приложение не используется посторонними людьми и не получает доступ к чужим каналам.

Nafilme Studio is the studio's own desktop tool. It uses Google sign-in only to upload finished episodes to the studio's own YouTube channels and to read their statistics (YouTube Data API v3). It is not offered to third parties.
